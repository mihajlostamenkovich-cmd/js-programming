# JavaScript Programming

A collection of JavaScript exercises covering programming fundamentals, organized by study day.

## Topics

- **Day 01:** variables, operators, conditionals, and loops
- **Day 02:** strings, arrays, functions, classes, and modules
- **Day 03:** error handling and inheritance

## Running an exercise

Install [Node.js](https://nodejs.org/), then run an individual file from the project root:

```sh
node day01/HelloWorld.js
```

Each file is a standalone practice exercise. `day03/ErrorHandling.js` intentionally throws an error to demonstrate custom errors.
